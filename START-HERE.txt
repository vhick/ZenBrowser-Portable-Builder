ZEN BROWSER PORTABLE - CROSS-PC PREVIEW

1. Place all these builder files into your existing GitHub builder repository.
2. Commit and push using GitHub Desktop.
3. Actions > Build Zen Browser Portable ZIP (Manual) > Run workflow.
4. Download the generated portable application ZIP.
5. To upgrade an existing Zen, preserve the original Data folder and replace App, Other and the root ZenBrowserPortable.exe only.
6. Launch ZenBrowserPortable.exe. No activation or manual cleanup commands.

This preview has been tested statically and must still be run on a clean Windows PC before zero-setup portability is confirmed. If unknown remnants appear, the cleanup script preserves rather than blindly deletes them.
